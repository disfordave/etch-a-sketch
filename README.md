# Etch-a-Sketch

A simple browser-based pixel drawing pad built with HTML, CSS, and vanilla JavaScript.

## Quick start
1. Open `index.html` in any modern browser (or use a local server such as VS Code Live Server).
2. Drag across the grid to draw. Use the slider and **Select** to change grid density, pick a color with the color input, toggle **Eraser** to remove strokes, and hit **Clear** to reset the board. Touch input is supported.

## Project structure
- `index.html` – markup and controls
- `css/style.css` – layout and styling
- `js/app.js` – canvas grid logic and interactions

## Notes
- Canvas size adapts to viewport width.
- No build step or dependencies required.
